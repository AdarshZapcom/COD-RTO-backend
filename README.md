# COD-RTO

RTO Signal Investigator — an AI agent for Quessathon 2026 Retail Challenge 01: Find the Signal.

Investigates incoming Cash-on-Delivery (COD) orders for Return-to-Origin (RTO) risk, reconciles
conflicting customer/courier/pincode signals, and decides RELEASE / HOLD FOR VERIFICATION /
ESCALATE TO A HUMAN.
